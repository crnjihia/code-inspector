            ⚡ SHA-256 Redis Cache Acceleration Impact
          

          

            Identical code blocks hash to identical SHA-256 keys. Subsequent audits bypass LLM inference entirely, slashing costs and dropping latency from ~1.2s to 32ms.

          Deployment & Configuration
          
Quickstart Setup

          

            Get your backend running in 60 seconds with Docker Compose or Node.js local development mode.
          

        


        

          
          
          
        


        
        

          

            

              docker-compose.yml
              
            

            
# 1. Clone repository
git clone https://github.com/crnjihia/code-inspector.git
cd code-inspector

# 2. Configure .env with your Anthropic key
cat < .env
PORT=3000
ANTHROPIC_API_KEY=sk-ant-api03-your-actual-key
CODE_INSPECTOR_API_KEY=your-bearer-token
REDIS_URL=redis://redis:6379
EOF

# 3. Spin up Backend + Redis 7
docker-compose up -d

# 4. Verify API health
curl http://localhost:3000/health

          

        


        
        

          

            

              Terminal / Bash
              
            

            
# 1. Install dependencies across workspaces
npm install

# 2. Build TypeScript workspaces
npm run build

# 3. Start backend in local dev mode (auto in-memory cache fallback)
npm run start --workspace=backend

# 4. Run automated test suites
npm run test

          

        


        
        

          

            

              settings.json
              
            

            
{
  "codeInspector.apiUrl": "http://localhost:3000",
  "codeInspector.apiKey": "your-bearer-token"
}
